### 3.1 PDF Rendering Engine: `PyMuPDF` (`AGPL-3.0`) vs. Permissive Alternatives

| Candidate | Software License | Rendering Fidelity & Speed | CJK / Font Handling | Commercial SaaS Suitability & Trade-Offs |
| --- | --- | --- | --- | --- |
| **`PyMuPDF` (`pymupdf 2.1`)** *(Current v0.1)* | **GNU AGPL-3.0** (or paid Artifex commercial license) | Very fast (~65–95 ms/page at 144 DPI); mature MuPDF core | Built-in `china-ss` (`Droid Sans Fallback`, Apache-2.0) | **Unsuitable for proprietary SaaS without license action:** network SaaS usage triggers AGPL-3.0 full-service source disclosure unless a commercial license (~USD $3k+/yr) is purchased. Ideal only for private R&D (`v0.1`). |
| **`pypdfium2` + `Pillow` + `NotoSansCJK`** *(Recommended v0.2 Target)* | **Apache-2.0 / BSD-3-Clause** (PDFium) + **HPND/MIT-CMU** (Pillow) + **SIL OFL-1.1** (Noto CJK) | Fast (~80–120 ms/page via Google PDFium native wheels); ~22 MB wheel | PDFium renders embedded PDF fonts natively; pair Pillow watermark layer with `fonts-noto-cjk` (`OFL-1.1`) | **Best zero-royalty commercial option:** Drop-in replacement for `doc[page].get_pixmap()` in `packages/watermark-engine/render_page.py` (~35 LOC change) with zero AGPL contagion and `$0` licensing cost. |
| **`pdfplumber` / `pdf2image` (`poppler`)** | MIT wrapper over **GPL-2.0/3.0** `pdftoppm` CLI | Slower (~180–350 ms/page; spawns external `pdftoppm` binary) | Requires OS `poppler-data` | Suboptimal: adds OS package coupling (`poppler-utils`) without outperforming `pypdfium2`. |

- **Recommendation:** Retain `pymupdf==2.1` for local research evaluation (`M006`–`M010`), and execute a targeted 1-file swap in `packages/watermark-engine/render_page.py` to **`pypdfium2` + `Pillow` + `fonts-noto-cjk`** prior to external pilot deployment (`M011` Milestone 2, `$0` software license cost).

### 3.3 Session Lifecycle & Sustainable Deployment Architecture

- **Session Security Model:** ContentVault now enforces a **dual-bound session lifecycle** (`2h` rolling idle timeout + `12h` absolute maximum lifetime in `src/security/authz.js`) with `HttpOnly; SameSite=Strict; Secure` cookies behind TLS. For production pilot launch, add session rotation on privilege change and an explicit "Revoke All My Sessions" user action (`DELETE FROM sessions WHERE user_id = ?`).
- **Sustainable Low-Cost Pilot Topology (~USD $30–$45 / month total, well within M011 USD $1,500–$3,000 12-month budget):**
  1. **Reverse Proxy / TLS Edge:** Caddy or Cloudflare proxy terminating TLS 1.3 (`CV_TRUST_PROXY` pinned strictly to the proxy's internal CIDR/loopback).
  2. **Application & Worker Host:** Single 2-vCPU / 4 GB RAM Linux VPS or container running Node 22 LTS (`NODE_ENV=production`) + warm Python `pypdfium2` worker pool (keeping a persistent worker pool of 2–4 Python processes eliminates ~45 ms per-request interpreter startup overhead).
  3. **Storage & Database:** Private S3-compatible bucket (Cloudflare R2 or Supabase Private Storage with server-only IAM keys; zero public bucket ACLs) + managed PostgreSQL with RLS enabled and append-only `audit_log` role permissions (`GRANT INSERT, SELECT ON audit_log TO app_role;` — revoking `UPDATE` and `DELETE` at the PostgreSQL role level).
